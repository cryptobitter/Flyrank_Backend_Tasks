# FlyRank Backend Tasks & Internship

Repository containing assignments, case studies, and deliverables for the FlyRank AI Internship.

## Repository Structure

- [**Assignment_1/**](./Assignment_1): Flask API setup and basic endpoints.
- [**What Are You Proving/**](./What%20Are%20You%20Proving): Week 01 proof statement, one-line why, and narrowing interview breakdown.
- [**Work That Speaks for Itself/**](./Work%20That%20Speaks%20for%20Itself): Week 02 framed case studies (the three beats), voice card, bio/CTA copy, and before/after editing analysis.
- [**The Prompt Ladder/**](./The%20Prompt%20Ladder): Systematic prompt engineering ladder (baseline + 5 iterative layers, regression analysis, and final reusable backend prompt).
- [**Prompting Fundamentals on Real Tasks v2/**](./Prompting%20Fundamentals%20on%20Real%20Tasks%20v2): 6-iteration prompt engineering log on FL-01 database layer, cross-model comparison (Claude vs. ChatGPT), and reusable backend systems template.
- [**W3-A2/**](./W3-A2): Week 3 Assignment A2 — Connecting CRUD API to a persistent SQLite database (`tasks.db`), manual SQL exploration, optional extras (`LIKE` search, status filter, alphabetical sort, `COUNT(*)` stats, timestamps, indexes, atomic transactions), and Stage 6 AI vs. Me code review.
- [**A3 Containerize your stack/**](./A3%20Containerize%20your%20stack): Assignment A3 — Containerized FastAPI + PostgreSQL (with persistent Docker volume and `init.sql`) + Redis stack via `docker-compose.yml`, swapping `InMemoryTaskRepository` for `PostgresTaskRepository` without changing service or routes, plus `EXPLAIN ANALYZE` index benchmarks.
- [**Consistency, Not Talent (and Frame, Not Upstage)/**](./Consistency,%20Not%20Talent%20%28and%20Frame,%20Not%20Upstage%29): Week 03 deliverable — One-line claim (from 10 options), 3-page content & CTA map with honest pre-build gather list, one-page Visual Identity Kit (`Inter` + `JetBrains Mono`, 4 WCAG-verified hex codes, custom SVG favicon, two-line style note), and curated real work captures with AI rejection analysis.
- [**Decide Once - Build Your Identity Kit/**](./Decide%20Once%20-%20Build%20Your%20Identity%20Kit): Week 03 Identity Kit deliverable — One-page visual identity specimen (`identity-kit-one-page.png`, `index.html`), typography pairing (`Inter` + `JetBrains Mono`), 4-color WCAG-verified palette (`#1E293B`, `#0F172A`, `#F8FAFC`, `#0D9488`), SVG wordmark logo & monogram favicon (`logo.svg`, `favicon.svg`), and two-line Claude Project style note.
- [**Kill your darlings - Curate Your Images/**](./Kill%20your%20darlings%20-%20Curate%20Your%20Images): Week 03 Image Curation deliverable — Content-map image inventory, final curated image set (`keepers/` real cropped captures of PostgreSQL `EXPLAIN ANALYZE`, SQLite DB Browser, and code diffs + 3-icon connective tissue SVG set in locked Identity Kit style), and graded rejection analysis (`rejected/`).
- [**The Through-Line - Map Content & CTAs/**](./The%20Through-Line%20-%20Map%20Content%20&%20CTAs): Week 03 Content & CTA Map deliverable — Sharpened one-line claim (from 10 AI options), 3-page ordered section & CTA ladder blueprint (`content-map-blueprint.png`), and honest pre-build "still need to gather" audit.
- [**Auth - Login & protect/**](./Auth%20-%20Login%20&%20protect): Supabase Auth & JWT Route Protection API (`POST /auth/signup`, `POST /auth/login`, `POST /auth/logout`, `GET /public/info`, `GET /protected/profile`, `GET /protected/dashboard`), reusable `HTTPBearer` middleware/dependency (`auth_middleware.py`), Swagger UI authorization at `/docs`, `pytest` verification suite, and Stage 7 AI vs. Me security review.
- [**Empty but Live - Ship a Blank Page/**](./Empty%20but%20Live%20-%20Ship%20a%20Blank%20Page): Week 04 Empty but Live deliverable — Near-blank live starter portfolio page (`index.html`, `favicon.svg`) built on the chosen stack (Semantic HTML5 + Vanilla CSS Custom Properties locked to the Week 03 Identity Kit), Three Roads stack rationale, desktop + mobile phone live verification screenshots (`live-desktop-and-mobile-verification.png`), and the consolidated Claude Project context bundle (`claude-project-context.md`) uniting the Identity Kit, Framed Case Studies, and Content Map for Week 05.
- [**Three Roads/**](./Three%20Roads): Week 04 Three Roads deliverable — Four real portfolio constraints given to AI, three distinct stack options with trade-offs (Road 1: No-Code vs. Road 2: Plain HTML5/CSS on GitHub Pages/Netlify vs. Road 3: Next.js Framework), four-question pressure test (`ai-interrogation-log.md`), visual decision matrix (`three-roads-decision-matrix.png`), and written rationale in own words.
